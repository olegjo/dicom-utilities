# Purpose
After completing this module, the learner should understand what the most important DICOM tags mean, and how their value affects interpretation, sorting and display of the DICOM files in nordicMEDiVA.

We will look at, the following tags
* SeriesInstanceUID
* SeriesDescription
* StudyInstanceUID
* StudyDescription
* PatientName
* PatientBirthDate
* Rows
* Columns
* SliceGap
* SliceThickness
* PixelSpacing
* PixelRepresentation
