# Activities - DICOM Data model

## Activity 1

Open a DICOM file using dcmdump and identify Patient name, Rows, Columns, Pixel data, SeriesInstanceUID, StudyInstanceUID, SOPClassUID.

> Discuss in a group: what are the significance of these tags?

## Activity 2
Inspect the DICOM header of a single frame, a mosaic and an enhanced MR DICOM file.

> What are the significant differences?
